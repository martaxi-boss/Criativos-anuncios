# Consolidação — Criativos-anuncios

A pasta raiz deste repositório contém o motor, workflow GitHub Actions, Skill com nome **criativos-anuncios**, exemplo de cinco imagens e testes contratuais.

Origem do protótipo: execução bem-sucedida no repositório Lowcost Europa (GitHub Actions #39321551165), cuja migração deve ser fechada sem integrar o PR experimental #160 nesse website.

Os materiais do exemplo são referenciados por URLs públicos; não estão embutidos neste repositório. Para criar anúncios de clientes, só usar imagens e áudio cuja licença/autorização esteja verificada. Não publicar anúncios automaticamente.

A interface nova da Skill é **Criativos-anuncios**; a identidade técnica preexistente do plugin pode conservar o slug `viral-ugc-chatgpt` enquanto o pacote for atualizado in situ, evitando plugins duplicados.

GitHub Actions está limitado pela cota do plano GitHub. O workflow gera ficheiros e prova as cinco fotografias e a existência de voz, mas não substitui audição humana do anúncio.
